# A Barca Brasil — site

Site estático (HTML + CSS + JS puro). Não precisa de build.

## Publicar no GitHub Pages
1. Crie um repositório (ex.: `barca-site`) e envie todos estes arquivos para a raiz.
2. No repositório: **Settings → Pages → Build and deployment → Source: Deploy from a branch**, branch `main`, pasta `/ (root)`.
3. Em 1–2 minutos o site fica em `https://SEU-USUARIO.github.io/barca-site/`.

## Estrutura
- `index.html` — a página
- `media/` — vídeos (.mp4, 720p) e capas (.jpg)
- `clientes/` — logos dos clientes (.webp)
- `barca-logo.svg`, `barca-mark.svg`, `mountains.webp` — identidade

Dependências externas: Google Fonts (Bebas Neue, Montserrat) e three.js r128 (cdnjs).
